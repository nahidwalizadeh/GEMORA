 GEMORA | Precious Stones

GEMORA  is a luxury gemstone website inspired by the natural beauty and timeless elegance of precious stones.

About the Project
This project presents a collection of eight precious gemstones, featuring their descriptions, characteristics, jewelry galleries, and estimated market prices.

 Features
- Elegant dark and gold luxury design
- Collection of eight precious gemstones
- Detailed gemstone information
- Jewelry image galleries
- Estimated gemstone prices
- About and Contact sections
- Responsive design for mobile, tablet, and desktop

 Technologies Used
- HTML5
- CSS3
- Google Fonts

 Project Structure
- `index.html` — Main webpage
- `style.css` — Website styling
- `images/` — Website images
